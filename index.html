Вопросы

Частые вопросы

Это правда бесплатно?

Да. LoveAI использует бесплатные ИИ-модели и сам выбирает самую сильную из доступных.

Что нужно для начала?

При первом запуске нажми «Обновить план» и вставь API-ключ — это делается один раз. Дальше просто пиши задачи.

Windows пишет, что файл может быть опасным

Так Windows реагирует на новые программы без платной цифровой подписи. Нажми «Подробнее» → «Выполнить в любом случае».

Где хранятся мои проекты?

Прямо на твоём устройстве — внутри приложения. Никуда не загружаются, кроме запроса к ИИ.

Как обновить LoveAI?

Никак — само. Программа на компьютере ставит обновление при перезапуске, Android показывает «Вышла новая версия», веб-версия обновляется при открытии.

Нужен ли интернет?

Да, чтобы ИИ отвечал. А вот уже готовые проекты открываются и без сети.
